SECURITY & TRUST

Built like the data it holds matters.

Resident data is encrypted in transit and at rest. Every gate record is append-only — no admin can alter or delete a logged entry, and each action carries the identity that performed it. Roles are enforced server-side: a guard never opens a billing ledger, a resident never sees another flat's ticket.
